# Engineering Lessons

- Public MCP catalogs must be deterministic. Provider discovery can validate compatibility but must never add or remove public tools.
- Confirmation-gated gameplay writes should use narrow transaction types rather than a general conversational runtime.
- Shared production databases require code-first rollout: deploy code that no longer depends on old tables before running a controlled table-drop migration.
- Repository cleanup guards must scan source, configuration, documentation, skills, mobile metadata, and ownership files—not only runtime imports.
- Preserve unrelated deterministic market automation when removing obsolete conversational infrastructure.
