# Contributing to Sportfolio

Sportfolio is publicly viewable source-available software, not an unrestricted open-source contribution project.

## Issues, Reports, and Suggestions

Bug reports, feature requests, compatibility reports, documentation corrections, and security reports are welcome. Security vulnerabilities must be reported privately according to `SECURITY.md` rather than through a public issue.

## Code and Content Contributions

Do not submit source code, artwork, substantial documentation, data sets, or other copyrightable material unless the maintainer has expressly invited the contribution and provided the applicable contributor agreement.

A pull request may be closed without review when no contributor agreement is in place. This policy preserves a clear copyright chain so the project can continue to offer both noncommercial public terms and separately negotiated commercial licenses.

When contribution terms are provided, the contributor must confirm that:

- the contribution is original or properly authorized;
- the contributor has the right to grant the required rights;
- the contribution does not contain confidential information, credentials, proprietary code, or incompatible third-party material;
- all third-party licenses and notices have been disclosed;
- the contribution may be included in noncommercial and commercial Sportfolio distributions under terms selected by the project owner.

Nothing in a discussion, issue, pull request, or code review grants commercial rights to Sportfolio or changes the repository license.
