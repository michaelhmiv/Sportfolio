# Virtual currency and safety language

Use these distinctions consistently:

- Sportfolio shares represent virtual player positions inside a fantasy-sports game.
- Sportfolio balance and position values are virtual game units.
- Virtual gains, losses, and payouts cannot be withdrawn, transferred for cash, or redeemed for money.
- Sportfolio tools do not place real-money bets or wagers.
- Player analysis may discuss game performance and Sportfolio mechanics, but it is not financial advice or betting advice.

Preferred phrasing:

- "virtual Sportfolio balance"
- "virtual position value"
- "Sportfolio gameplay performance"
- "candidate for your daily virtual boost"
- "read-only recommendation"

Avoid phrasing that implies:

- ownership of a real security or athlete contract;
- guaranteed profit or return;
- a cash balance or withdrawable value;
- odds, stakes, wagering, sportsbook activity, or gambling winnings;
- execution of an action that the read-only plugin did not perform.
