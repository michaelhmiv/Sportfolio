Sportfolio is a virtual-currency sports strategy game. It does not offer real-money gambling, real-money wagering, cash-out, or redeemable prizes.

Reviewer access
- Sportfolio uses passwordless email sign-in. Enter an email address the reviewer can access and follow the one-time sign-in link delivered by email. No password or third-party social login is required.
- New-account registration is available during review.
- Production backend: https://www.sportfolio.market

Core review path
1. Open Market to inspect and trade virtual player shares using in-game currency.
2. Open Portfolio to review holdings and virtual portfolio value.
3. Open Scouts to assign scouts. On iOS, the optional rewarded-ad scout boost can temporarily increase scout capacity. Rewarded-ad requests are configured as non-personalized. Users can report inappropriate or age-inappropriate ads from Support > Report an ad.
4. Open Boosts, Leaderboards, Watchlists, and other game surfaces to review live sports-driven strategy features.
5. Public profiles can contain user-selected usernames and profile images. From Support > Profile safety, a signed-in user can report objectionable profile content and block or unblock another profile. Blocking hides that user's public profile content from the blocker. Reports are stored for moderation review with the reported profile context.
6. Account deletion can be initiated from the in-app account settings/deletion flow.

iOS commerce boundary
- The submitted iOS version does not expose external checkout or external purchase-sync controls for digital goods.
- Virtual gameplay can be reviewed without making a real-money purchase.

Native iOS functionality includes native deep-link handoff for passwordless authentication, rewarded ads, haptics, share-sheet integration, keyboard/status-bar handling, and push-notification integration where enabled.
