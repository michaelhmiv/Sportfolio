# Plugin Icon Checklist

- [x] Uses the existing Sportfolio `SF` mark from the repository as the visual source.
- [x] Square 1024 × 1024 master canvas.
- [x] Self-contained SVG; no remote assets or font dependencies.
- [x] High contrast at small sizes.
- [x] No added wording, taglines, photographs, or UI screenshots.
- [x] Artwork remains centered and proportionally scaled.
- [x] Ready to import into the official Plugin icon template and export using that template's configured PNG settings.
- [ ] Final PNG export visually inspected in the editable Figma template before submission.
