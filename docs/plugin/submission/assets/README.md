# Sportfolio ChatGPT Plugin Icon

This directory contains the submission-specific Sportfolio icon derived from the canonical application artwork at `client/public/favicon.png`.

## Asset

- `sportfolio-plugin-icon.svg` — 1024 × 1024, self-contained vector artwork based on the canonical black circular Sportfolio badge and green `SF` monogram.

## Placement in the OpenAI Figma template

1. Import `sportfolio-plugin-icon.svg` into the linked Plugin icon template.
2. Center it horizontally and vertically in the artwork frame.
3. Scale proportionally. Do not stretch, crop, rotate, recolor, add text, or add another background shape.
4. Keep the complete circular badge visible inside the template safe area.
5. Do not manually round the outer canvas unless the template itself applies that mask.
6. Export the template’s final submission frame as PNG using the dimensions and export settings defined in that template.

## Validation

- Square 1024 × 1024 canvas.
- Canonical repository artwork used as the source.
- Aspect ratio preserved.
- No wordmark or small text added.
- Self-contained SVG with no external image or font dependencies.
- Brand treatment follows Sportfolio’s documented emerald-green-on-dark visual system.

The connected Figma account has view-only access to the public template, so the repository contains a template-ready import asset rather than a modification to the original template file.
