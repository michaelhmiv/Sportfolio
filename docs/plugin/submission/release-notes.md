# Release notes — Sportfolio Companion 1.0.0

This is the initial public submission of Sportfolio Companion.

The plugin combines a read-only MCP server with a Sportfolio-specific skill. It provides public documentation, player, and game research and lets users connect a Sportfolio account through OAuth 2.1 to review virtual holdings, virtual balance, watchlists, boosts, collections, milestones, news, game insights, and read-only setup recommendations.

Version 1 intentionally excludes all write capabilities, credentials, SMS/OTP workflows, API-token management, billing, premium redemption, profile changes, schedules, virtual trade execution, liquidity operations, and dynamically discovered sidecar tools.

Reviewer credentials are supplied separately in the submission portal. The reviewer account contains synthetic fixture data and does not require MFA, SMS, email confirmation, VPN access, or private-network access during review.

Sportfolio shares, balances, values, gains, losses, and payouts are virtual gameplay units with no cash value. Sportfolio does not provide real-money betting, wagering, cash prizes, or cash-out functionality.
