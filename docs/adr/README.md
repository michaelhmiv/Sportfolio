# Architecture Decision Records (ADRs)

Use ADRs to capture medium/long-lived technical decisions, especially for economics,
agent orchestration, and architecture boundaries.

## Naming

- `NNNN-short-title.md` (e.g., `0001-route-and-storage-modularization.md`)

## Required sections

- Context
- Decision
- Consequences
- Validation

Start from `docs/adr/TEMPLATE.md`.
